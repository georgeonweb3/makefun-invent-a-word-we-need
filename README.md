One invented English word, defined in a single clear line of at most 140 characters. Free to enter, judged in pairs on whether the word fills a real gap, whether the definition lands in one reading, and whether the word is sayable, spellable and memorable.

The entry (93 characters):

> landclapper (n.) — the passenger who applauds the moment the plane’s wheels touch the runway.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (UTF-8, no trailing newline).
